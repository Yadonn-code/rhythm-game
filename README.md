# ゆきあかりリズム

雪国が舞台のリズム・ミニゲーム集（オリジナル）。HTML / CSS / JavaScript だけで動き、ビルドは要らない。
画像や音声のファイルは使っていない。絵は Canvas で、音（曲・効果音）は Web Audio でその場で作っている。

## 遊び方

- `index.html`（入口）をダブルクリックし、PC版かスマホ版を選ぶ。直接開くなら `pc/index.html` か `sp/index.html`
- VSCode で開発するときは、拡張機能「Live Server」を入れて `index.html` を右クリックし「Open with Live Server」を選ぶ。保存するたびにブラウザが自動で更新される
- Bluetooth イヤホンを使うと音が遅れて聞こえるので、メニューの「タイミング調整」→「自動で調整」をやっておく

| 版 | 操作と特徴 |
|---|---|
| PC版 `pc/` | スペース / Enter / Z / クリックで叩く。メニューでは 1・2 キーでスタート、S でタイミング調整、F で全画面。結果画面では Enter でもう一回、Esc でメニューに戻る |
| スマホ版 `sp/` | 画面のどこをタップしてもよい。横向きなら画面いっぱいに表示する。縦向きなら上がゲーム画面、下が大きなタップ面と案内文になる。Android では叩いたときに振動する。「ホーム画面に追加」するとアプリのように全画面で開ける |

| ミニゲーム | ルール |
|---|---|
| 🪓 まき割りベア | キツネが「ポン」と放った丸太を、1拍後の着地に合わせて割る。2本続けて飛んでくるパターンもある。大きい丸太は「ドン…タ・タ・パッカーン」で、2拍後に割る |
| 🦉 ふくろうの灯り | 長老ふくろうが1小節のあいだ鳴いたリズムを、次の小節でそっくりまねする |

## ファイル構成

- `index.html` … 入口。PC版とスマホ版を選び、端末に合うほうに「おすすめ」を付ける
- `pc/index.html` + `pc.css` … PC版
- `sp/index.html` + `sp.css` + `sp/manifest.webmanifest` … スマホ版（縦向きのときのタップ面 `#pad` もここにある）
- `style.css` … 両版に共通する、メニューと結果画面の見た目
- `icon.svg` / `icon-*.png` … アイコン
- `game.js` … ゲーム本体（両版で共通）。`<body data-platform="pc|sp">` を見て動きを切り替える。上から順に次のブロックが並んでいる
  - 音：`SFX`（効果音）、`scheduleSong()`（コード進行から伴奏を組み立てる）
  - 背景とキャラクター：`drawBear` / `drawFox` / `drawOwl`
  - ミニゲーム：`LUMBER`（まき割り）、`OWLS`（ふくろう）
  - 進行管理：`press()`（判定）、`finish()`（採点）

## 譜面の直し方

- まき割り：`LUMBER.chart` に 1小節 = 8文字（1文字 = 8分音符）で書く。`l` は小さい丸太、`b` は大きい丸太、`.` は休み
- ふくろう：`OWLS.calls` に `[長老が鳴く小節, [8分音符の位置 0〜7]]` の形で書く。プレイヤーの番は、その次の小節になる
- テンポは各ゲームの `bpm` で、曲の長さは `song.bars`（小節の数）で変えられる

## ミニゲームの足し方

`LUMBER` と同じ形のオブジェクトを作り、`GAMES` に登録すると、メニューにカードが自動で増える。
必要なメソッドは次のとおり。

- `setup(c)` … 合図の音を `c.at(拍, 音)` で、判定のタイミングを `c.addTarget(拍, 種類, データ)` で登録する
- `onPress` / `onHit` / `onWhiff` / `onMiss` … 押したとき・当たったとき・空振りしたとき・見逃したときの演出
- `draw(beat)` … いまの拍の位置に合わせて画面を描く
- `comments(stats)` … 結果画面に出すアドバイス

## 判定の仕組み

押した瞬間の時刻を「いまスピーカーから聞こえている音の時刻」（`heardAt()`）に置き換えて、譜面の時刻と比べている。

| 判定 | ずれの幅 | 点数 |
|---|---|---|
| ジャスト | ±45ms 以内 | 100点 |
| ナイス | ±90ms 以内 | 75点 |
| おしい | ±140ms 以内 | 30点 |
| ミス | それ以上ずれた・押さなかった | 0点 |

空振り（合図がないところで押したとき）は、1回ごとに1.5点引く。
